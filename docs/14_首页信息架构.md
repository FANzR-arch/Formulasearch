# 首页信息架构：第一版

## 参考边界

本页借鉴 `antfu.me` 当前首页的三个原则：低存在感导航、连续的第一人称自述、用链接和简短事实建立可信度。不会复刻其文字、徽标、品牌资产、项目列表或版面数值。

## 页面顺序

```text
小型导航
  ↓
名字 + 一句话身份 + 三条实践线索
  ↓
Work：AI tools / Visual systems / Web & discovery
  ↓
Writing：说明文章在全站中的作用，不放未经核验的文章清单
  ↓
Resources：明确 Skills、工具、模板、工作流的长期入口
  ↓
About / Now：当前状态、联系、下一步
```

## 设计规则

- 单栏阅读骨架，避免“Hero → 卡片网格 → 转化按钮”的 SaaS 构图。
- 纸面色 + 微弱点阵是背景材质；橙褐色只用于编号与动作提示。
- 第一版不依赖图片；信息密度和排版先成立，后续只将已经授权、可说明来源的工作素材插入相应章节。
- 动效只承担进入与悬停反馈，且遵守 `prefers-reduced-motion`。不设置访客等待、长转场或装饰性滚动特效。

## 首批内容接入规则

1. `Work` 只接有真实问题、角色、产出、状态的项目；名称与链接在源头核验后再公开。
2. `Writing` 只接正文在本站可读、具备作者与日期的文章。
3. `Resources` 只接能安装、下载、复制或在线使用的明确条目。
4. 每一个条目必须有独立 URL，并在相关项目、文章与资源之间建立自然内链。
