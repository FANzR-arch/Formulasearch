## 1. 定位（相对 v0.3 规划的修正）

**首页第一句：我做过的每件事，都变成了你能直接拿走用的东西。**

这句话是全站的轴。它同时解决三件事：向客户证明能力、给读者一个关注理由、把散落的
skill / 模板 / 工具收进同一个叙事。别人的作品集说不了这句话。

### 相对 `00_网站规划.md` v0.3 的三处修正

| 项 | v0.3 | v0.1 框架 | 依据 |
|---|---|---|---|
| 站的性质 | 一人公司获客门面，SEO/GEO 第一性约束 | **名片 + 资产货架**，不以获客为第一目标 | Phil 2026-08-05 明确 |
| 建筑背景 | 「过去→现在」叙事主线之一 | **身份行一句带过，不设板块** | Phil 2026-07-31 判断 + X 数据：同行点赞但对多数人不是卖点 |
| 提示词/Skills | 「Skills 货架」是七板块之一 | **货架是网站主体**，审美分享系列是主角 | GitHub 916★ + 日更系列 + 系列转化 1.8 倍 |

### 网站的第一个真实作用：接住正在漏掉的流量

- 命理 skill 长文：链接点击 **4,350** → 全部落在 github.com
- GPT-Image-2 合集：链接点击 **4,768** → 同上

这些人已经动手点了，但落地页不在自己域名下。**不是「要不要做站」，是「已有流量没地方接」。**

## 2. 导航：五项

七板块按「访客怎么用」重新归并：

```
货架   拿走就能用：审美分享系列 · Skills · 工具
写作   实践经验与思考，长文为主
作品   建筑设计 · AI 视觉 · 摄影
业务   网站搭建 · SEO&GEO，一页说清
关于   身份、数据、联系、X 入口
```

课程（SEO 课站 / 交易课站）**不占导航**，从业务页和作品页外链。

### 三种内容形态，三套陈列方式

| 形态 | 内容 | 页面要解决 |
|---|---|---|
| 拿走就用 | 审美分享、Skills、工具 | 好找、能搜、一键拿走 |
| 坐下来读 | 长文、思考 | 好读、有分类、**正文在自己域名下** |
| 扫一眼看 | 建筑、AI 视觉、摄影 | 图大、加载快 |

**不要用一套卡片样式套三种内容**——这是很多个人站看着别扭的原因。

## 3. 页面清单

| 图号 | 页面 | 角色 |
|---|---|---|
| A-01 | 首页 | 名片，30 秒讲清你是谁 |
| A-02 | 货架（总览） | 仓库主体，三区块 |
| A-03 | 审美分享 · 完整系列 | **全站转化最高的一页** |
| A-04 | 单个资产页 | 全站数量最多的页面类型 |
| A-05 | 写作 | 正文必须在自己域名下 |
| A-06 | 作品 | 建筑 / AI 视觉 / 摄影 |
| A-07 | 业务 | 用「客户拿到什么」写，不用「我提供什么服务」写 |
| A-08 | 关于 | 全站唯一集中放数据的地方 |

### 三个关键零件（结构上最不能省的）

1. **首页直接露出最新三期审美分享**，而不是一个「Skills」入口按钮
   → 系列转化率是一次性内容的 1.8 倍，露出期数就是在露出「下次还有」
2. **系列页 = Phil-aesthetic-formulas 的 README 表格**（期数/主题/类型/拿走/原帖）
   → 这张表你已经写好了，只是埋在 GitHub。同样内容排成系列，形态从 0.147% 变 0.360%
3. **单资产页底部的「上一期 / 下一期」**
   → 「一堆东西」和「一个系列」的唯一区别

### 固定用语（沿用已定标准，不另起一套）

- 资产页固定标签：**「适用场景」「使用方式」**（2026-08-01 定，不换词）
- 场景写读者的痛，不写技术参数
- 命令从 README 读，不能编
- 图一乐的不上货架

## 4. X 的位置

**X 是发生地，网站是沉淀地。** 不镜像推文、不嵌内容流。

X 在站内只出现两处：
1. 单资产页底部一行来源标记：「来自 审美分享-06 · 2026-08-04 · 看原帖 ↗」
2. 页脚 / 关于页的链接入口

### 数据展示

放一处（关于页）+ 页脚，三个数：

| 数据 | 值（2026-08-06） | 备注 |
|---|---|---|
| GitHub | **916★**（Numerologist_skills） | 最硬的一个，别人真装到了自己电脑上 |
| X 粉丝 | 8,610 | 会过期，考虑写「8,000+」或定期更 |
| 审美分享 | 已更新至第 N 期 | 可自动算（数仓库文件夹数） |

**不放**：单条推文爆款数据、月展示量——那是运营复盘指标，对访客没意义。
