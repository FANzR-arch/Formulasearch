# Formulasearch 正式项目基线

状态：`v0.1` 首页可运行；其他页面先保留内容模型与导航位置，不能以占位内容冒充已上线内容。

## 产品定位

这是 Phil 的个人实践站，不是 SaaS 官网，也不是传统作品集模板。它同时承担两件事：

1. 让第一次来的人在约 30 秒内理解 Phil 是谁、做什么、可以从哪里继续了解。
2. 长期承载可独立分享的项目、文章、Skills、工具与合作案例。

## 第一版信息架构

```text
/
├─ /work          项目与合作案例
├─ /writing       文章与观察
├─ /resources     Skills、工具、模板、工作流
└─ /about         个人路径、当前状态、联系信息
```

首页暂以锚点完成这些入口，等各栏目的首批真实内容核验完成后再拆为路由。这样不会制造空页面或未来必须迁移的假 URL。

## 技术基线

- Astro 静态站点：HTML 优先，便于性能、SEO 与长期内容维护。
- TypeScript strict：内容模型与组件改动可检查。
- 每页默认具备独立 `title`、description、canonical、Open Graph 与 Person JSON-LD。
- `robots.txt` 已允许抓取；`llms.txt` 作为机器可读的站点摘要。
- 构建命令：`npm run build`。本地预览：`npm run dev`。
