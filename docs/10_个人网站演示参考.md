# 个人网站演示参考：第二轮

> 更新：2026-08-07  
> 目标：补充上一轮没有覆盖的新案例，并把参考网站转成可比较的演示路线。  
> 当前仍处于调研阶段，本文件不代表已经选定视觉方案或开始开发。

> 多平台继续调研：见 [`11_多平台个人网站补充调研.md`](11_多平台个人网站补充调研.md)。新增了 X 交互原型、中文建筑作品集、Reddit 可用性反馈和 B站完整演示核对。

## 先看结论

这轮不建议继续按“好看的网站”漫无目的地收集。Formulasearch 现在有三个需要被演示验证的问题：

1. **整体视觉系统长什么样**：网格、排版、图片、元信息与动效如何共存。
2. **大量不同资产怎么放**：Skills、工具、文章、作品和业务如何形成一个长期增长的平台。
3. **精选内容与完整档案怎么分层**：首页不能塞完所有内容，但也不能只剩一张视觉海报。

对应最值得先看的三个网站：

| 顺序 | 网站 | 先观察什么 | 对 Formulasearch 的直接价值 |
|---|---|---|---|
| 1 | [Corentin Bernadou](https://corentinbernadou.com/) | 首屏、Featured Works、Archive、List/Overview 切换、项目元信息 | 最接近“瑞士骨架 + 档案密度 + 编辑型大图”的整体演示 |
| 2 | [Mike van der Sanden](https://mikevandersanden.com/) | 首页如何串联文章、资源、代码示例、工具和实验 | 它把个人站定义成 Personal Project Platform，而不是传统作品集，和“个人资产货架”高度同构 |
| 3 | [Artem Shcherban](https://artemshcherban.com/) | 一屏视觉入口、文字索引、弹层预览、精选项目与一般项目的区别 | 证明首页可以有强视觉，但访客仍能用两次点击抵达完整内容 |

如果只留半小时，按上面的顺序浏览，不需要先看后面的五个。

## 路线 A：编辑型档案

### 1. Corentin Bernadou

- 实站：[corentinbernadou.com](https://corentinbernadou.com/)
- 制作拆解：[Inside Corentin Bernadou’s Portfolio](https://tympanus.net/codrops/2026/03/05/inside-corentin-bernadous-portfolio-swiss-inspired-layouts-webgl-geometry-and-thoughtful-motion/)

值得借：

- 先画结构和浏览路径，再决定视觉与技术。
- 瑞士式网格不是“纯文字极简”，而是给大图、编号、年份、角色和说明建立秩序。
- `Featured Works / Archive` 把精选展示与完整收录分开。
- `List / Overview` 允许同一批内容以高密度清单和视觉概览两种方式浏览。
- 3D/WebGL 只作为界面上方的一层，不取代正文和真实链接。

不要照搬：

- 不需要一开始就上 WebGL。先用普通图片、位移和裁切验证布局。
- 橙、白、黑是它的识别色，不是 Formulasearch 的现成配色答案。

适合演示：**全站视觉骨架**。

### 2. Stefan Vitasović

- 实站：[stefanvitasovic.dev](https://stefanvitasovic.dev/)
- 制作拆解：[Stefan Vitasović Portfolio 2025](https://tympanus.net/codrops/2025/03/05/case-study-stefan-vitasovic-portfolio-2025/)

值得借：

- 偏移网格、留白、粗排版和视频缩略图共同形成强烈视觉。
- 字符组合成单词的动效与“代码由字符构成”的概念有关，不是随意添加的装饰。
- 页面转场、噪点和故障效果使用同一套运动语言。

不要照搬：

- WebGL、全屏转场、噪点和光标效果不能同时成为首版依赖。
- 动效概念属于开发者身份，Formulasearch 应从自己的“资产被拿走、展开、组合”中找运动母题。

适合演示：**结构确定后的动效语言**。

### 3. Isabel Moranta

- 实站：[isabelmoranta.com](https://www.isabelmoranta.com/)
- 制作拆解：[Isabel Moranta Portfolio 2024](https://tympanus.net/codrops/2024/12/05/case-study-isabel-moranta-portfolio-2024/)

值得借：

- `About / Work / Archive` 三层关系很清楚。
- 高对比衬线标题承担情绪，等宽小字承担项目事实和元信息。
- 模糊效果反复表达“模糊与转变”，让个人表达和专业项目属于同一个人。

不要照搬：

- Formulasearch 的首屏不能只靠引语和氛围，需要立即露出五个入口。
- 黑底大字可以作为局部密度，不必成为全站唯一模式。

适合演示：**专业能力与个人气质如何合并**。

## 路线 B：个人资产平台

### 4. Mike van der Sanden

- 实站：[mikevandersanden.com](https://mikevandersanden.com/)
- 制作拆解：[The Making of a Personal Project Platform](https://tympanus.net/codrops/2025/09/17/the-making-of-a-personal-project-platform-a-portfolio-that-grew-out-of-process-and-play/)

值得借：

- 网站明确承载 thoughts、projects、resources、code examples 和 live tools。
- 内容类型不同，但共享统一的标题、标签、图片、状态与链接组件。
- 首页有一个可玩的视觉实验，下面仍然是可读、可扫、可进入的真实内容。
- 把建站过程、组件、代码和实验本身继续变成可分享资产。

不要照搬：

- 可绘制的 Canvas 是它自己的玩具，不等于我们的首页也必须放一个游戏。
- 不能因为叫“平台”就把首页做成后台或文件管理器仿真。

适合演示：**货架、写作、工具和作品之间的内容关系**。

### 5. Jackie Zhang

- 实站：[jackiezhang.co.za](https://jackiezhang.co.za/)
- 制作拆解：[From Chasing References to Finding Direction](https://tympanus.net/codrops/2026/03/20/jackie-zhangs-portfolio-from-chasing-references-to-finding-direction/)

值得借的不是涂鸦风格，而是方法：

- 先写清楚喜欢参考里的什么，再限制颜色、材质、字体和图形来源。
- 把“快速捕捉想法”翻译成笔记本、便签、涂鸦和翻卡交互。
- 每一种视觉元素都能回到同一个概念，而不是靠 moodboard 拼贴。

对 Formulasearch 的提醒：

- “瑞士感”“编辑感”还只是形容词，需要继续翻译为网站自己的概念。
- 可以尝试的母题包括：资产上架、展开说明、复制拿走、版本迭代、不同实践互相连线。

适合演示：**从参考图走向自己的视觉概念**。

## 路线 C：分层视觉入口

### 6. Artem Shcherban

- 实站：[artemshcherban.com](https://artemshcherban.com/)
- 制作拆解：[Designing Against the Gallery](https://tympanus.net/codrops/2026/05/02/designing-against-the-gallery-a-two-year-journey-to-a-layered-portfolio-experience/)

值得借：

- 它明确反对把所有项目铺成同一种 Gallery。
- 首页用一个视觉场景建立印象，同时保留 `Index / About / Portfolio / Blog / Resume` 的文本入口。
- 一般项目先弹出数张图和基本信息，访客理解后再进入详情。
- 精选项目获得特殊视觉，一般项目保持系统化列表，避免每一项都争抢注意力。
- Blog 使用信息栏、正文栏和目录处理长文。

不要照搬：

- Cookie、声音许可和教学提示会增加首次进入阻力。
- Formulasearch 不需要把导航藏成寻宝游戏，首屏就应看见主要入口。

适合演示：**强首屏、快速索引和内容弹层如何共存**。

### 7. Gianluca Gradogna

- 实站：[gianlucagradogna.com](https://gianlucagradogna.com/)
- 制作拆解：[Gianluca Gradogna Portfolio ’25](https://tympanus.net/codrops/2025/01/30/case-study-gianluca-gradogna-portfolio-25/)

值得借：

- 设计作品和摄影共用一套视觉语言，但摄影拥有独立的横向浏览方式。
- 动效主要依靠位置、透明度和裁切，不必把所有变化交给复杂 3D。
- 大图可以建立世界观，白色信息卡负责可读性。

不要照搬：

- 无限滚动容易让人失去当前所在位置，不适合替代完整索引。
- 摄影是否进入 Formulasearch 首发范围仍未拍板，因此它属于条件型参考。

适合演示：**如果摄影进入首发，如何与设计作品并存**。

### 8. Federico Pian

- 实站：[federicopian.com](https://www.federicopian.com/)
- 制作拆解：[Federico Pian Portfolio 2024](https://tympanus.net/codrops/2024/10/02/case-study-federico-pian-portfolio-2024/)

值得借：

- 数字键直达项目，方向键切换项目，让档案不仅能点，也能快速扫。
- 页面转场保持当前项目与下一项目的空间连续性。
- 视觉实验没有取消键盘导航和基本可访问性。

不要照搬：

- 快捷键是增强功能，不能代替清晰导航。
- 圆形几何属于它的身份，不需要迁移到 Formulasearch。

适合演示：**档案页的键盘浏览和转场连续性**。

## 建议只做三套同内容演示

下一轮如果要出视觉演示，不建议再画六个互不相关的首页。三套都使用同一批真实内容，才看得出差异来自设计，而不是来自换文案和换图片。

### 演示 1：Editorial Archive

参考组合：Corentin + Dinamo + Cloudflare Blog。

- 首屏：身份、五入口和一张当前主视觉同时可见。
- 首页：精选 4 项；下方用编号目录接完整内容。
- 货架：`List / Overview` 双视图。
- 详情：大图、版本、适用场景、使用方式、相关教程。
- 动效：悬浮预览、图像裁切、轻量页面转场。

这是目前最稳妥的主方向。

### 演示 2：Personal Project Platform

参考组合：Mike + Formulasearch 的真实资产关系。

- 首屏：一句身份和“最近上架”视觉实验。
- 首页：Skills、工具、文章和作品不按栏目平铺，而按“最近更新 / 可直接拿走 / 正在构建”组织。
- 每个条目保留类型、状态、版本、使用入口和来源。
- 建站过程本身可以进入 Revisions 或 Changelog。

这套最能检验“资产货架”是不是网站真正的结构，而不只是定位文案。

### 演示 3：Layered Visual Hub

参考组合：Artem + Catherine Bui + Isabel Moranta。

- 首屏：一张强视觉或短循环视频，文字导航常驻。
- 悬浮条目时展示多图预览和极短说明。
- 精选 4 项使用特殊展示；完整档案保持规整清单。
- 长文与资产详情仍回到稳定的阅读网格。

这套最有个人气质，但也最容易因为动效和弹层过多而变慢。

## 三套演示必须共用的内容

为了避免“看起来都不错但无法比较”，三套演示固定使用：

- 同一句身份说明。
- 同一套五项导航：货架、写作、作品、业务、关于。
- 同一批 8 个首发条目：3 个视觉 Skill、1 个其他 Skill、1 个工具、1 篇文章、1 个作品、1 个业务入口。
- 同一套图片素材与元信息。
- 同一移动端宽度和 `prefers-reduced-motion` 降级要求。

比较时只回答五个问题：

1. 访客能否在 30 秒内知道你是谁、这里有什么？
2. 首屏有没有明确入口，还是只有一张漂亮海报？
3. 内容变到 50、100、300 项后，结构还能不能继续用？
4. Skills、文章和作品看起来属于同一个人，又能否一眼区分？
5. 去掉动效后，页面是否依然成立？

## 本轮判断

- **第一优先看 Corentin**：它把现有方向第一次变成了较完整、可操作的网页系统。
- **第二优先看 Mike**：它帮助判断 Formulasearch 到底是作品集，还是持续增长的个人项目平台。
- **第三优先看 Artem**：它给出“精选内容特殊处理、完整档案保持系统化”的具体办法。
- Stefan、Isabel 负责补充动效与气质，不负责决定信息架构。
- Jackie 提供设计方法，不提供可直接照搬的视觉外观。
- Gianluca 和 Federico 是条件型参考，分别解决摄影和键盘浏览。

因此，下一步不是继续增加参考数量，而是从上面的三个演示方向中选 1–2 个，用同一批真实内容出首页和货架页对照。
