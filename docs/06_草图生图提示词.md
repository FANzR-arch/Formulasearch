## 方向一 · 瑞士国际主义网格

**定位**：你最早初选的方向。严格网格 + 超大字 + 单一信号色。
**适合**：业务页、首页——对客户显专业。
**风险**：装不下档案馆式的高密度内容，货架页可能显空。

```

Layout: a strict 12-column modular grid, everything flush left, generous margins. Thin hairline rules separate the horizontal bands.
— Top bar: small wordmark "Formulasearch" at far left; navigation "货架 写作 作品 业务 关于" set small and evenly spaced at far right.
— Hero band filling the upper half: one small grey line "不想画图的建筑师 → AIGC 设计师 & 架构师", and beneath it an enormous three-line headline set flush left across nearly the full width: "我做过的每件事，都变成了你能直接拿走用的东西".
— Lower band: three equal-width cells in a row, each containing only a very large numeral — "006", "005", "004" — with one short caption line under each.

Typography: Chinese headline in Source Han Sans Heavy (思源黑体 Heavy), very tight leading, optically aligned. Latin words in a neutral grotesque. Navigation and captions very small, same family, regular weight.

Color: warm white paper ground, near-black text, and one single signal red used only on the three numerals and one hairline rule. Flat color only.

Feel: Swiss international typographic style — objective, silent, structural. The grid should be felt, never decorated.

Avoid: gradients, glassmorphism, rounded corners, drop shadows, icon sets, emoji, stock photography, purple or blue tech palette, centered layout.

3:2 landscape.
```

## 方向二 · 档案馆索引

**定位**：高密度、编号、细分隔线，像图书馆目录卡。
**适合**：货架页、系列页——你的核心内容形态。
**风险**：纯档案式对卖建站服务的站太冷，可能吓退客户。

```
A flat web design mockup of a personal website homepage that looks like an archive index — rendered as a clean full-bleed screenshot, no browser chrome, no device frame.

Layout: information-dense, almost no decorative space. Everything organised as ruled rows and columns, like a library catalogue or a museum accession register.
— A slim top bar: "Formulasearch" at left, "货架 写作 作品 业务 关于" as a plain inline text list at right, separated by thin vertical bars.
— A short statement block, modest in size, not a hero: "不想画图的建筑师 → AIGC 设计师 & 架构师" on one line, "我做过的每件事，都变成了你能直接拿走用的东西" on the next.
— The bulk of the page is a long ruled table of entries. Each row: a zero-padded index number at left ("006", "005", "004"), then a title, then a small type label, then a date, then a right-pointing arrow. Hairline rules between every row. Alternating rows very slightly tinted.

Typography: Chinese in Source Han Sans Regular (思源黑体) at small sizes, set tight. Index numbers and dates in a Latin monospace with tabular figures. No large display type anywhere — the page's power comes from density and alignment, not scale.

Color: cool off-white ground, dark graphite text, hairlines in light grey, and one muted ink accent used only on index numbers.

Feel: a working archive, not a portfolio. Quiet, dense, scannable, faintly bureaucratic. It should look like it contains hundreds of entries and could contain thousands more.

Avoid: hero sections, large imagery, cards with rounded corners, gradients, shadows, icon sets, emoji, decorative illustration.

3:2 landscape.
```

## 方向三 · 建筑制图

**定位**：图框、标题栏、尺寸标注、细线。**你的母语。**
**适合**：首屏做一次性表达、关于页。
**风险**：整站都这样会很累，也难维护。建议当"某一处的语言"而不是全站基调。
**已有 skill**：`engineering-blueprint-sheet`（选中后配图可直接调）

```
A flat web design mockup of a personal website homepage drawn in the visual language of an architectural working drawing — full-bleed screenshot, no browser chrome, no device frame.

Layout: the whole page sits inside a drawing frame with a ruled border and corner registration marks. A title block occupies the lower right corner containing "Formulasearch", a sheet number, a date, and a scale note.
— Navigation "货架 写作 作品 业务 关于" appears as a row of labelled tabs along the top edge of the drawing frame, each in a small ruled box.
— The centre of the sheet carries the statement, set as if lettered on a drawing: "不想画图的建筑师 → AIGC 设计师 & 架构师" as a small annotation, and "我做过的每件事，都变成了你能直接拿走用的东西" as the main lettering.
— Three schematic rectangles are laid out along the lower third, each tagged with a bubble callout numbered "006", "005", "004", with leader lines and dimension arrows running between them.

Typography: Chinese set in Source Han Sans Light (思源黑体 Light) with wide letter spacing, imitating drafting lettering. Latin annotations, sheet numbers and dimensions in a light monospace with tabular figures.

Color: pale drafting-paper ground with a very faint blue-grey cast, all linework in a single dark ink, one brick-red used only for callout bubbles and revision marks. Line weights must vary meaningfully — heavy for the frame, medium for structure, hairline for dimensions and grid.

Feel: a real construction document that happens to describe a website. Precise, technical, slightly cold, entirely linear.

Avoid: photographs, gradients, filled color blocks, shadows, rounded corners, glassmorphism, icon sets, emoji, blueprint-cyanotype cliché with white lines on saturated blue.

3:2 landscape.
```

## 方向四 · 陈纸编辑

**定位**：大留白、纸质、中文宋体大标题、一个高饱和色点。
**适合**：写作板块、作品板块。安静，有人味。
**风险**：留白型撑不住高密度货架。
**已有 skill**：`quiet-paper-specimen`

```
A flat web design mockup of a personal website homepage with the restraint of a fine editorial print page — full-bleed screenshot, no browser chrome, no device frame.

Layout: generous, asymmetric white space. Content sits low and left, leaving the upper right largely empty. Nothing is centred.
— A very small top line: "Formulasearch" at left, "货架 写作 作品 业务 关于" at right, both nearly whispering.
— A single large Chinese headline set in Source Han Serif (思源宋体) with high stroke contrast, occupying the left two-thirds across two lines: "我做过的每件事，都变成了你能直接拿走用的东西". Above it, much smaller and in grey: "不想画图的建筑师 → AIGC 设计师 & 架构师".
— Along the bottom edge, three modest entries separated by wide gaps, each labelled only "006", "005", "004" in small figures with a one-line caption.

Typography: Source Han Serif for the headline, high contrast, moderate weight, comfortable leading. Everything else in a small light sans. Numerals in an old-style Latin serif.

Surface: the ground is aged paper — a warm off-white with visible fibre texture, faint uneven tone, and a barely perceptible fold or scan edge. The texture must be subtle enough to read as paper, not as a filter.

Color: aged warm paper, ink-black type, and exactly one small area of high-saturation color — a single vermilion dot or short bar placed near one of the numerals. Nothing else is colored.

Feel: quiet, considered, printed rather than rendered. The emptiness is the design.

Avoid: gradients, glassmorphism, rounded cards, drop shadows, icon sets, emoji, stock photography, symmetrical centred layout, cream-and-terracotta template look.

3:2 landscape.
```

## 方向五 · 新粗野主义

**定位**：粗黑边框、硬偏移阴影、扁平撞色块。
**适合**：货架——组件感天然对应"一件件货"，而且辨识度最高。
**风险**：和"克制专业"有张力，业务页可能显得不够稳重。
**已有 skill**：`neo-brutalist-poster`

```
A flat web design mockup of a personal website homepage in a neo-brutalist web style — full-bleed screenshot, no browser chrome, no device frame.

Layout: everything is a hard-edged rectangular block with a thick black border and a solid offset shadow displaced down-right. Blocks butt against each other with visible gutters. Nothing is rounded, nothing is soft.
— Top bar: a bordered black-outlined strip containing "Formulasearch" at left and five separate bordered nav chips at right: "货架" "写作" "作品" "业务" "关于".
— A large bordered block dominates the upper area, filled flat with a single saturated color, containing "我做过的每件事，都变成了你能直接拿走用的东西" in heavy Chinese type. A smaller bordered strip above it holds "不想画图的建筑师 → AIGC 设计师 & 架构师".
— Three bordered blocks in a row below, each a different flat color, each containing a huge numeral: "006", "005", "004".

Typography: Chinese in Source Han Sans Heavy (思源黑体 Heavy), large, tight, unapologetic. Latin numerals in a heavy grotesque. No thin weights anywhere.

Color: an off-white paper ground, pure black borders and type, and three flat saturated fills that clash rather than harmonise — pick hues outside the blue-purple range, for example a hot red-orange, an acid yellow-green, and a deep magenta. Flat fills only, no tints or gradients.

Feel: assembled from parts, physical, a little rude. It should look built rather than styled — like a shelf of objects, not a brochure.

Avoid: gradients, glassmorphism, soft blurred shadows, rounded corners, pastel palettes, icon sets, emoji, stock photography, thin elegant type.

3:2 landscape.
```

## 方向六 · 暖纸拟物

**定位**：奶油纸底 + 扁平 UI 卡片 + 一件写实道具同框。
**适合**：首页做一次有温度的表达；也最像"做过网站的人做的网站"。
**风险**：拟物元素多了会显得营销味重，且难保持一致。
**已有 skill**：`paper-workflow-hero`

```
A flat web design mockup of a personal website homepage where flat interface elements and one photoreal physical object share the same frame — full-bleed screenshot, no browser chrome, no device frame.

Layout: a cream paper ground. Flat vector UI cards with crisp edges are arranged on the left two-thirds; a single photorealistic physical object sits at the right, casting a soft real shadow onto the paper, overlapping the edge of one card.
— A slim flat top bar: "Formulasearch" at left, "货架 写作 作品 业务 关于" at right.
— A flat card holding the statement: "不想画图的建筑师 → AIGC 设计师 & 架构师" small and grey above, "我做过的每件事，都变成了你能直接拿走用的东西" large beneath in Source Han Sans Medium (思源黑体).
— Three small flat cards in a row along the bottom, labelled "006", "005", "004".
— The photoreal object is an architect's tool rendered with real material weight — a scale ruler, a mechanical pencil, or a folded drawing — placed as if left on the desk, not as a product shot.

Typography: Chinese in Source Han Sans (思源黑体), Medium for the headline, Regular elsewhere. Latin numerals in a warm humanist sans.

Color: cream paper ground, warm dark brown-black text, muted terracotta and sage as the only two accents on cards. The photoreal object keeps its natural material color.

Feel: a designer's desk, flattened into an interface. The contrast between the flat vector layer and the one real object is the whole idea — keep everything else flat so that contrast reads.

Avoid: gradients on the flat layer, glassmorphism, rounded oversized corners, drop shadows on flat elements (only the real object casts one), multiple photoreal objects, icon sets, emoji, 3D rendered UI.

3:2 landscape.
```

## 选定之后再跑这三张

首屏定了方向，再用同一套语言跑其余页面。届时只需把上面选中那条的**风格段照抄**，换掉布局段：

| 图 | 换成什么布局 | 为什么要单跑 |
|---|---|---|
| **系列页** | 一张长表：期数 / 主题 / 类型 / 拿走 / 原帖，十几行 | 这页是全站转化最高的，密度撑不撑得住只有画出来才知道 |
| **单资产页** | 大预览图 + 「适用场景」「使用方式」两栏 + 底部上下期导航 | 全站数量最多的页面类型 |
| **货架总览** | 三个区块，每区一种陈列方式（期数排 / 目录排 / 清单排） | 验证"三种内容不用一套卡片"能不能成立 |

## 我的判断

真要下注的话：**方向一（瑞士）和方向二（档案）是同一个骨架的两端**，很可能最终答案是它们的融合——
瑞士管首页和业务页（对客户），档案管货架和系列页（对读者）。这个融合在 `03_参考去哪找.md`
结尾已经提过一次，这轮生图正好可以验证它成不成立。

方向三、四、五、六更适合当**局部语言**而不是全站基调，但值得各跑一张——
风险最高的方向五（粗野）反而可能最适合货架，因为"一件件货"天然就是组件感。
