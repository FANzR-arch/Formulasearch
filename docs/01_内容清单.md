| 简笔人说明插图 | outline-figure-explainer |
| 网点 UI 拼贴封面 | halftone-ui-collage |

**19 套 skill 里至少 19 套都有配对文章。** 这不是巧合，是你的工作流：做一个 skill → 写一篇分享文。

### 对信息架构的影响

**Skills 和博客不是两个板块，是同一批东西的两个面：**

```
skill  = 拿走就用（装上直接出图）
文章   = 看懂为什么（这个风格怎么拆的）
```

### ✅ 2026-08-06 拍板

**Skills 保持独立板块，图为主、文字为辅。**

- Skill 详情页 = **样例图 + 怎么用 + 拿走按钮**，另附一段短介绍
- 文字介绍**不是重点**，不在 skill 页放整篇长文
- 配对的那 19 篇分享文仍留在博客板块（内容资产不浪费），skill 页底部挂一条「完整拆解 →」链过去

即：**一份内容两个入口，但主次分明**——想拿就走 Skills，想看懂去博客。
