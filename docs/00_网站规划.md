## 1. 定位

**一人公司（Company of One）官网 × 个人表达阵地**，双重身份，一个站：

| 身份 | 服务对象 | 对应内容 |
|---|---|---|
| 一人公司门面 | 潜在客户、合作方 | 业务介绍、交付案例、成果、信任背书 |
| 个人表达阵地 | 同行、读者、学员 | 作品、思考/博客、Skills、探索历程 |

两者不冲突：**作品和思考本身就是一人公司最好的获客内容**。客户看到的是能力证明，读者看到的是真实的人。

命名沿用 **Formulasearch**（与 X 账号一致），品牌统一。

## 3. SEO / GEO 策略（新增，第一性约束）

> 这个站同时是你 SEO/GEO 能力的**活案例**——「我的官网就是我方法论的实证」，本身可写进业务介绍。

### 技术 SEO（架构层，选型时就要满足）
- 静态生成（SSG）优先，每页独立 URL、服务端可渲染完整 HTML
- 语义化结构：每页唯一 H1、正确标题层级、面包屑
- 双语 hreflang 配对（zh/en 各自独立 URL，如 `/zh/...` `/en/...`）
- sitemap.xml、robots.txt、规范 canonical、OG/Twitter 卡片
- 结构化数据（schema.org）：`Person` + `Organization`（一人公司）、`Product`（作品）、`Article`（博客）、`Course`（课程）、`Service`（业务线）、`FAQPage`
- 性能预算：LCP < 2.5s，图片全量优化（旧站已有 sharp 优化脚本可参考思路）

### 内容 SEO（v0.3 调整：SEO 主力 = 业务页 + 案例，博客 = 表达本位）
- **SEO 主引擎是两个业务落地页 + 案例页**：瞄准服务型搜索词（如「个人作品集网站搭建」「工作室官网定制」「GEO 优化」「AI 搜索优化」等，具体词表开发前调研）
- **博客回归表达本位**：写什么由你决定，类型多样不设限；只做基础 SEO 卫生（标题、描述、分类标签、独立 URL），不为关键词扭曲选题。文章中自然提到产品/服务时做内链即可
- 案例页（cases）是转化枢纽：每个交付案例写成「客户是谁 → 问题 → 做了什么 → 结果」，同时喂 SEO（长尾词）和 GEO（可引用事实）
- 内链网络：文章 ↔ Skill ↔ 产品 ↔ 业务页互链

### GEO（让 AI 引擎引用你）
- `llms.txt` + 每页干净的 Markdown 可读版本
- 事实密集的「可引用页」：关于页、产品页写成 AI 容易摘取的事实陈述（谁/做了什么/数据/时间）
- FAQ 结构：业务页、产品页带问答块
- 一致的实体信息：全网统一「Fan Zheren / 阿哲 Phil / Formulasearch」称谓、简介、链接（X、GitHub、小红书同步）
- 你 SEO-learn 课程里的 GEO 方法论直接在本站落地 → 反过来成为课程的案例素材
