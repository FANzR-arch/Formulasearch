# 参考去哪找（2026-08-03）

> 配套 `02_参考记录.md` 使用。这份是"渔"，那份是"鱼"。
> 当前方向：档案馆/索引式 + 瑞士国际主义（二选一或融合，待定稿）

## 0. 为什么之前搜不到有感觉的

按风格名搜（"瑞士风格网站""极简作品集"）搜出来的是 SEO 列表文，收录标准是"截图好看"，
里面没有一个站需要同时装作品 + 文章 + 工具 + 课程 + 业务页。样子货解决不了结构问题。

改成两个维度搜：

1. **策展源**：有人替你筛过质量的地方（画廊、字体厂、档案馆）
2. **结构相似**：内容类型和你一样多的真实个人站——看别人怎么不乱

### A2. 字体厂商站 = 瑞士设计的日常实践

比任何"瑞士风格教程"都准——这些站每天都在用网格和大字排版承载**真实商业内容**（卖字体、讲授权、做案例）。
正好也是你"业务页 + 作品页"要解决的同一个问题。

- [Grilli Type](https://www.grillitype.com/)（GT 系列，瑞士本土）
- [Dinamo](https://abcdinamo.com/)（柏林/巴塞尔，网格玩得野一点）
- [Lineto](https://lineto.com/)（瑞士老牌）
- [Optimo](https://www.optimo.ch/)、[Swiss Typefaces](https://www.swisstypefaces.com/)
- [Klim Type Foundry](https://klim.co.nz/)（新西兰，但排版和案例页写得极好）

### A3. 档案 / 博物馆（档案馆方向的原型）

档案馆式的视觉语言是从这些地方来的。看原型比看模仿品准。

- [archives.design](https://archives.design/) — 设计档案聚合
- [Letterform Archive 在线馆藏](https://letterformarchive.org/online-archive/)
- [Museum für Gestaltung Zürich eMuseum](https://museum-gestaltung.ch/en/exhibition/swiss-design-collection) — 瑞士设计藏品约 2500 件，**瑞士 + 档案两个方向的交集，优先看**
- Swiss Posters Collection — 19 世纪至今数字化瑞士海报
- [Are.na](https://www.are.na/) — 平台本身就是档案馆美学；搜 channel 关键词 `swiss`、`archive`、`index`、`grid`

## C. 收参考时记什么（否则收了等于没收）

`02_参考记录.md` 那张表，"喜欢什么"一栏**不要写"好看""干净""高级"**。写这三件事之一：

1. **它怎么处理"内容类型多"**：导航分几层？首页优先给谁看？次要内容藏在哪？
2. **信息密度档位**：一屏塞多少东西？留白是奢侈型还是节省型？
3. **一处你会抄的具体做法**：某个列表样式、某种标签、某个页脚结构。具体到能复述

第 3 条最重要。收了 20 个站说不出 20 条具体做法，就是白收。

## D. 一个筛选提醒

你的站是"网站搭建"业务的样品，客户点进来是在验货。
所以参考里那些**纯个人自嗨型**的站（比如极端档案馆式）可以借结构，但不能整体照搬——
`sive.rs` 那种"零设计"放在卖建站服务的站上，是自杀。

融合的可能性值得在定稿时认真考虑：**瑞士的骨架（网格、克制、大字）+ 档案馆的密度（列表、标签、可检索）**。
前者管首页和业务页（对客户），后者管作品/Skills/博客索引（对读者）。
