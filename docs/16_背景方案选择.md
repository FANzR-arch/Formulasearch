# 首页背景方案

网站保留三种自动背景，并在每次刷新时随机选择一种。系统会避免连续两次出现同一个背景。

- **Dither**：位于页面两侧与角落的双层彩色点阵波纹；增加矿物冷暖色层次和点阵密度，但不覆盖正文中心。
- **焦散**：更清晰的液态亮纹；颜色扩展为钴蓝、孔雀青、琥珀与铜橙，并以珍珠色强化高光。
- **柔波**：较安静、低饱和度的双层彩色轮廓；主轮廓外增加一层柔和回声，提高辨识度。

原独立“折光”方案已经删除。只将它的配色逻辑复用到“焦散”的原有液态纹理中，不保留宽幅色散、薄膜或折叠形态，也不进行两种特效叠加。

页面不再显示背景选择器。点击左上角 Logo，可按 `Dither → 焦散 → 柔波` 的顺序切换；刷新页面后仍重新随机，并避免连续两次出现同一个背景。Logo 按钮支持键盘操作，并通过无障碍标签告知当前与下一个背景。

## 统一约束

- 背景必须第一眼可以看见，不能弱到需要刻意寻找。
- 效果保持局部，不铺满整页形成大色块。
- 正文中间区域保持安静、清晰、易读。
- 桌面端鼠标划过后，鼠标路径会写入原有流场的持续记忆，轻微改变之后的噪声采样和动态相位；不随鼠标离开而自动恢复。
- 桌面端每次主键按下时，只产生一次向外扩散的径向涟漪；新点击替换仍未消散的旧涟漪。
- 点击扰动只更新背景状态，不阻止链接、按钮、主题切换或背景切换等原有行为。
- 自动运动保持低速。
- 焦散保持缓慢流动，不快速闪烁，不改变正文布局。
- 手机、触摸、手写笔和系统开启“减少动态效果”时，不启用交互扰动；背景停在静态画面或保持原有非交互行为。

## 交互扰动约束

- 鼠标路径记忆只在本次页面生命周期内持续，不做回弹或衰减；点击涟漪约一秒内自然衰减。
- 当前交互强度控制在上一版约一半；涟漪先缓慢形成，再向外扩散并淡出，避免点击瞬间收缩。
- Dither、焦散、柔波都响应交互，但根据自身纹理密度使用不同强度，避免点阵和轮廓过度跳动。
- 鼠标记忆直接参与三个现有 `render...()` 的原始噪声和时间输入；不增加第二张画布、CSS filter、透明变形层或独立后处理效果。

这样可以让背景继续承担轻量氛围层的作用，同时给桌面端用户一个可感知但不喧宾夺主的反馈。
