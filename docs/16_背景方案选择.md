# 首页背景方案

网站保留三种自动背景，并在每次刷新时随机选择一种。系统会避免连续两次出现同一个背景。

- **Dither**：位于页面两侧与角落的双层彩色点阵波纹；增加矿物冷暖色层次和点阵密度，但不覆盖正文中心。
- **焦散**：更清晰的液态亮纹；颜色扩展为钴蓝、孔雀青、琥珀与铜橙，并以珍珠色强化高光。
- **柔波**：较安静、低饱和度的双层彩色轮廓；主轮廓外增加一层柔和回声，提高辨识度。

原独立“折光”方案已经删除。只将它的配色逻辑复用到“焦散”的原有液态纹理中，不保留宽幅色散、薄膜或折叠形态，也不进行两种特效叠加。

页面不再显示背景选择器。点击左上角 Logo，可按 `Dither → 焦散 → 柔波` 的顺序切换；刷新页面后仍重新随机，并避免连续两次出现同一个背景。Logo 按钮支持键盘操作，并通过无障碍标签告知当前与下一个背景。

## 统一约束

- 背景必须第一眼可以看见，不能弱到需要刻意寻找。
- 效果保持局部，不铺满整页形成大色块。
- 正文中间区域保持安静、清晰、易读。
- 背景只自动播放，不响应鼠标位置、速度或点击。
- 自动运动保持低速。
- 焦散保持缓慢流动，不快速闪烁，不改变正文布局。
- 系统开启“减少动态效果”时，背景停在静态画面。

## 已移除内容

- 删除鼠标推动、旋转和加速流场的全部交互代码。
- 删除黑洞按钮、随机选项、着色器和相关许可证说明。

这样可以减少突然变形和视觉干扰，让背景重新承担轻量氛围层的作用。
