## ★ 已选中（2026-08-06 阿哲拍板）

这四个进入定调子阶段，其余全部**待定保留**，不删。

### 1. [abcdinamo.com](https://abcdinamo.com/) —— 页面 + 配色

- **页面**：首页顶部一行文字目录（锚点式，点了不跳页、跳本页下方区块），下面每一项是一大块视觉展开。目录和视觉叠加而非二选一
- **配色**：待具体取样，收几张截图进 `refs/images/`

### 2. [calebbarclay.com](https://calebbarclay.com/) —— 界面 + 交互

- 简洁的界面 + 文字
- **光栅背景 + 鼠标动效** → 站方自己的说法：`Cursor light streak, reeded glass`（reeded glass = 竖棱/光栅玻璃）
- **拖动切换天气和配色** → 站方说法：`Scrub slider; continuous sky blending`；另有 `Time-of-day gradient; clock centered`
- 附带可抄的结构：首页那个 **Revisions 迭代日志**——把网站自己的构建过程当内容
- 字体：Grilli Type 的 **Super Display + Haptik**（站内明写）

> 交互实现要搜的关键词就用站方原话，比中文描述准。

### 3. [catherinebui.com](https://catherinebui.com/) —— 鼠标悬浮弹出的页面缩略图

- 作品列表在悬浮时弹出该站的截图预览，不用点进去
- 附带可抄的结构：作品条目是「客户 + 我做了什么 + 截图」，链接**直接指向真实上线的站**（figma.com/figjam、github.com/mobile、vsco.co）——做建站的人不写 case study 的做法

### 4. [blog.cloudflare.com/the-agent-access-model/](https://blog.cloudflare.com/the-agent-access-model/) —— 博客页排版与细节

- 已核验的**正文排版手法**：编号原则用「**加粗一句话标题** + 展开段」；新术语首次出现加粗定义（**Agent Access Model (AAM)**、**task execution graph**）；引述指令用斜体（_reconcile these two ledgers_）；小节标题是平白陈述句（"The shift"、"Why the human model does not transfer"），不是标题党
- ⚠️ 视觉层（阅读栏宽度、目录、代码块、配图、作者卡、标签）**未逐项核验**——抓取器只拿得到文字。需要阿哲指出具体是哪几处细节，或截图存 `refs/images/`

**四者的隐含共识**：calebbarclay 用 Grilli Type 字体，而 Grilli Type 与 Dinamo 同为瑞士/德语区字体厂——**字体方向已隐隐收敛到这一支**。
