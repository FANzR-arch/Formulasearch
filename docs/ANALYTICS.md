# 网站访问与内容关注统计

使用免费的 Google Analytics 4（GA4），不依赖 Vercel Pro。入口为 <https://analytics.google.com/>。

## 开通与发布

1. 已创建网站数据流 `rzcwebsite`，网址 `https://rzcthink.top`，衡量 ID 为 `G-18WV54GK34`。
2. 保留数据流中的「增强型衡量」总开关，在齿轮设置中关闭「滚动」「出站点击」「视频互动」「表单互动」，避免与本站埋点重叠或采集无关表单行为；页面浏览、站内搜索和文件下载可保留。本站自行发送页面访问、内容点击和阅读进度，GA4 自身的会话与参与度指标仍由官方标签处理。此面板不会列出本站自定义事件。
3. 代码默认使用此 ID，无需额外配置 Vercel。若将来更换资源，可在 Vercel 项目的 Settings → Environment Variables 中配置 `PUBLIC_GA_MEASUREMENT_ID` 覆盖默认值；明确设为空则停用。该 ID 是公开配置，不是密码。
4. 重新构建并部署。打开正式网站，再在 GA4「实时」中确认访问和事件；标准报表通常需要 24–48 小时处理。

代码入口：`src/layouts/BaseLayout.astro` 和 `public/scripts/site-analytics.js`。未配置有效 ID、开发模式、预览域名及 iframe 均不会发送数据；仅在站点配置中的正式域名启用。单纯预加载页面文件不执行埋点，未来若使用浏览器预渲染，也会等用户真正打开再计数。

## 记录什么

| 事件名 | 含义 | 分析用途 |
| --- | --- | --- |
| `page_view` | 实际打开页面，每次页面访问一次 | 看哪些页面获得流量 |
| `navigation_click` | 点击主导航 | 看用户主动选择哪些栏目 |
| `content_click` | 点击正文、列表中的站内链接 | 看哪些内容入口吸引点击 |
| `outbound_click` | 点击项目、Skills、伙伴等外部链接 | 看哪些成果引起进一步探索 |
| `section_jump` | 点击当前页面的章节锚点 | 看页面内哪些主题受关注 |
| `keyword_open` | 展开首页关键词说明 | 看哪些个人经历或能力引起兴趣 |
| `photo_open` | 打开照片大图，每张每次访问只记一次 | 看哪些照片被主动查看 |
| `video_start` | 视频实际开始播放，每条每次访问只记一次 | 看哪些影像有人观看 |
| `content_engaged` | 开场结束后累计在前台且窗口有焦点 30 秒 | 区分短暂打开与持续浏览 |
| `content_progress` | 阅读文章至少 10 秒后到达 25/50/75/100% 深度，每档一次 | 看哪些文章有较深入的浏览 |
| `contact_click` | 点击 X、邮箱或微信入口 | 看哪些页面促成联系意向 |
| `ai_open` | 点击 AI 对话入口 | 评估数字分身入口兴趣 |

`content_engaged` 表示可见停留，`content_progress` 表示页面深度，都不能证明用户真的读懂内容。联系按钮被点击也不等于已发送邮件或添加好友。刷新或重新进入页面是新的页面访问；同一访问内重复播放、重复打开相同照片不会重复增加相应事件。

## 怎样看“更受关注”

GA4「管理 → 数据显示 → 自定义定义」中建立以下**事件级自定义维度**（显示名称可以中文）：

| 维度参数 | 建议名称 | 内容 |
| --- | --- | --- |
| `content_id` | 内容标识 | 站内路径、外部目标路径、关键词或照片编号 |
| `placement` | 点击位置 | 导航、内容章节或正文 |
| `site_language` | 界面语言 | zh / en |
| `percent_scrolled` | 阅读进度 | 25 / 50 / 75 / 100 |

`content_group` 为页面所属栏目，使用 GA4 内置「内容组」维度。中英文页面的站内内容标识合并，关键词按对应语言文字区分。

在「探索 → 自由形式」中，以「事件名称 → 内容标识」为行、「事件数、总用户数」为值，筛选 `content_click`、`outbound_click`、`video_start` 或 `photo_open`，即可比较内容兴趣。按「网页路径」比较页面浏览、`content_engaged` 和 `content_progress`，结合流量判断：曝光多不一定吸引人，曝光少也可能因为入口不明显。点击率或深入阅读比例必须使用相同时间、页面范围和分母口径，不直接用事件次数当人数。

首期不采集聊天正文、表单输入、邮箱地址、用户自填内容，也不启用 Google Signals 或广告个性化。页面地址、来源地址和外链目标移除查询参数及片段，避免携带临时标识；章节跳转只保留站内章节片段。内容标识最多 100 个字符。没有用户级自建 ID，不做跨站个人识别。

## 验证范围和限制

- 自动化测试拦截 Google 标签请求并检查发送队列，不向正式 GA4 制造测试访问；覆盖页面计数、去重、参数清理、前台阅读及预加载。
- 最终验收仍须在真实衡量 ID 配置、上线后，通过 GA4 实时面板核对。未接入前的历史访客无法回补。
- 广告拦截、禁用 JavaScript、Google 服务网络可达性都会影响采集；部分中国大陆访客可能无法上报，因此报表并非所有真实访问的完整计数。
