# Formulasearch icon system

生产页面的功能图标和自定义鼠标都从这里取用。`icons.ts` 是唯一注册表，`Icon.astro` 是唯一业务调用接口；业务组件不应直接导入 `@lucide/astro`，也不应覆盖图标尺寸或描边。

## 规格

- `meta`: 14px
- `control`: 18px
- `cursor`: 20px glyph，36px 光学圆环外壳
- 所有图标使用 1.75 描边、圆端点、圆连接和 `currentColor`

注册表按用途命名；重复使用的 `Plus`、`X` 等仍以不同语义名称管理。鼠标包含 10 个状态：普通、链接与控件、文字输入、照片导航、高亮、胶囊、媒体预览、打开照片、缩小照片、关闭查看器。

## 导航图标

导航使用用户从比较页选定的组合：`Camera`（照片）、`Landmark`（柱廊建筑）、`Link2`（伙伴站点）、`Globe`（切换语言）、`Sun` / `Moon`（目标主题）和独立的 `nav-chat: MessageCircleMore`。导航外的聊天图标仍使用原来的 `chat` 注册项。

`nav-icons.css` 仅作用于 `.site-header`，为现成 Lucide 图形增加一次性悬浮 / 键盘聚焦反馈，不引入动画库或重绘 SVG。照片镜头轻微收缩，建筑立柱依次变化，链接两端轻微靠拢，地球小幅转动。部分细节动画按 Lucide 子路径顺序定位，升级图标包后需检查建筑、链接和聊天的动作。品牌标志只做整体轻微移动和缩放。菜单箭头继续表达展开状态。

桌面文字提示直接读取实时 `aria-label`，语言 / 主题切换后自动同步；Escape 可隐藏提示，避免与原生 `title` 重复。940px 及以下的展开菜单显示文字标签。系统开启减少动态效果时，禁用这些动画和过渡。

博客、项目、技能、探索的文字与 `ChevronDown` 箭头共用一个链接和悬浮区域；点击文字或箭头均直接跳转，桌面悬浮或键盘聚焦展开分类菜单，不添加「查看全部」。箭头悬浮时轻点一次，展开时旋转 180°。键盘上下方向键进入首个 / 最后一个分类，Escape 关闭并返回主链接；手机点击主链接直接进入对应页面。

品牌 Logo、GitHub 官方标志、开场动画/博客装饰 SVG 和文章 Emoji 不属于功能图标系统，继续使用原有官方资源或装饰实现。
